---
  Как скачивать транскрипции с YouTube

  Инструмент: yt-dlp

  Установка (если нет):
  pip install -U yt-dlp

  Ключевой момент — JS runtime

  YouTube требует JavaScript runtime для извлечения данных. По умолчанию yt-dlp поддерживает deno. Если его нет — будет
  ошибка или частичная работа.

  Установка deno:
  curl -fsSL https://deno.land/install.sh | sh

  Или можно указать другой runtime (node, bun) флагом --js-runtimes.

  Команды

  Скачать автосубтитры (VTT):
  yt-dlp --write-auto-sub --sub-lang en --skip-download --sub-format vtt \
    -o "/path/to/output/%(id)s" "https://www.youtube.com/watch?v=VIDEO_ID"

  Получить список видео канала (последние 30):
  yt-dlp --flat-playlist -j --playlist-items 1-30 \
    "https://www.youtube.com/@ChannelHandle/videos"

  Получить метаданные видео (JSON):
  yt-dlp -j --no-warnings "https://www.youtube.com/watch?v=VIDEO_ID"

  Если YouTube блокирует

  1. Обновить yt-dlp — YouTube часто ломает старые версии:
  pip install -U yt-dlp
  2. Проверить наличие JS runtime (deno/node/bun)
  3. Добавить --no-warnings --quiet — иногда помогает с rate limiting
  4. Пауза между запросами — sleep 1-2 между видео
  5. Не качать само видео — флаг --skip-download, только субтитры/метаданные

  PATH

  Убедиться, что yt-dlp доступен:
  export PATH="$HOME/.local/bin:$PATH"
