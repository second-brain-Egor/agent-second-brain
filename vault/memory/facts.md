## 2026-04-08 — Системные ориентиры
- В домашнем каталоге пользователя есть файл `/home/egor/hybrid-init-prompt-v2.md`
- Пользователь ожидает, что `GLOBAL_RULES.md` читается перед запуском как основной операционный регламент
- Пользователь не хочет получать напоминания и навязанные дедлайны без прямого запроса
- Сборка рейсмуса и проект бани сейчас относятся к длинному горизонту планирования, а не к недельным задачам
- Пользователь хочет, чтобы ежедневная обработка работала автоматически, без ручного запуска
