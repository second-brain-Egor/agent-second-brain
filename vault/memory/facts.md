## 2026-04-09 — Сетевой сбой после WireGuard
- Пользователь не хочет пересказа содержимого фото экрана; нужен сразу вывод и действие
- После запуска PowerShell-скрипта переключения WireGuard интернет на Windows пропал
- По снимку `ipconfig /all`: Ethernet получил нормальный IPv4 `192.168.1.56`, шлюз `192.168.1.1` и DNS от роутера, значит локальная сеть жива
- Наиболее вероятная причина обрыва: активный WireGuard-туннель/маршрут после скрипта перехватывает трафик или оставляет kill-switch
- Для аварийных инструкций на Windows нужны короткие команды, которые можно ввести вручную без копирования

## 2026-04-13 — Уточнение формата и строительного фокуса
- В Telegram-ответах пользователю нужен чистый HTML без Markdown-символов и без голых ссылок; ссылку лучше прятать в слово или короткую фразу
- Визуальная структура ответа должна быть блочной: заметный старт блока, пустые строки только между смысловыми блоками, а не внутри короткого перечня
- На прямые технические вопросы пользователь ожидает ответ по сути в 1-3 коротких строках без лишнего описания устройства системы
- По проекту бани текущий полезный фокус — упорядочить материалы Forumhouse так, чтобы по ним можно было прикинуть материалы, фундамент и этапы строительства
- По скриншоту или фото интерфейса не нужно пересказывать содержимое; нужно сразу определить, где сейчас открыт пользователь, и дать следующий точный шаг
- На текущем этапе настройки: по маме работа остановилась на создании пользователя на удалённом сервере; по Ирине агент уже установлен, но настройка упёрлась в GitHub

## 2026-04-14 — Правила Telegram по итогам чата
- Если пользователь присылает фото для поиска аналога, модели или характеристик, не нужно описывать содержимое изображения, если он об этом не просил
- В ответах со ссылками на товары или модели гиперссылку нужно привязывать к названию модели, а не выводить URL отдельной строкой
- Карточки станков и товаров нужно оформлять визуально чище: модель отдельной строкой, характеристики вроде веса, питания, типа шипа и цены тоже отдельными строками
- Пользователь болезненно реагирует на повторы; если замечание уже прозвучало, не повторять ту же мысль в следующих сообщениях без новой причины

## 2026-04-14 — Контур подбора шипорезных станков
- Для подбора шипорезных станков пользователь опирается только на площадки Yahoo, Amazon и Rakuten
- В выдаче по станкам нужны только активные предложения; проданные лоты не подходят

## 2026-04-15 — Цифровой контур предприятия

- Промышленная безопасность
- Эксплуатация и ремонт
- Оперативное управление

- После уточнения структура была укрупнена до 7 направлений без отдельных подпунктов: `документы и знания` входят в `производство`, а `обучение и допуск персонала` остаётся отдельным направлением

- Промышленная безопасность
- Эксплуатация и ремонт

- Знания и готовность к событиям: документы, инструкции, история изменений, практический опыт, аварийная готовность и реагирование
