# Выгрузка данных с Regi и переезд бота

## Суть

Первостепенная инфраструктурная задача: полностью выгрузить данные с удалённого сервера Regi на 37-й компьютер, затем подобрать более дешёвый сервер и перенести туда Agent Second Brain.

Текущий сервер обходится примерно в 80-100 рублей в день, что слишком дорого для постоянного размещения бота и сопутствующих данных.

Задача в Todoist: `6gVpmrCFm2xRpGq2`.

## Главный порядок

1. Сначала сделать полную локальную выгрузку данных на 37-й компьютер.
2. Проверить, что выгрузка читается и содержит всё нужное.
3. Отдельно подобрать более дешёвый сервер.
4. Поднять на новом сервере рабочее окружение.
5. Перенести бота и данные.
6. Проверить Telegram-бота, память, задачи, логи, автозапуски и доступы.
7. Только после проверки думать об отключении старого сервера.

## Что обязательно выгрузить

- репозиторий Agent Second Brain;
- весь `vault`;
- конфиги окружения, включая `.env`, но хранить их отдельно и аккуратно;
- логи, если они нужны для диагностики;
- скрипты запуска, `systemd`-юниты, cron-задачи и deploy-скрипты;
- локальные дополнительные папки рядом с проектом, если они относятся к работе бота;
- данные Forumhouse/Барыги, если они лежат на том же сервере или связаны с переездом;
- инструкции и заметки по доступам, без публикации секретов в открытые файлы.

## Важные ограничения

- Не переносить бота вслепую, пока нет полной локальной копии.
- Не удалять и не отключать старый сервер до проверки нового.
- Не полагаться только на git: в git может не быть `.env`, логов, runtime-данных, сессий и локальных выгрузок.
- Секреты и токены не складывать в обычные заметки vault.
