# План выгрузки и переезда

## Цель

Сохранить полную копию данных со старого удалённого сервера Regi на 37-й компьютер и подготовить перенос Agent Second Brain на более дешёвый сервер.

## Этап 1. Инвентаризация старого сервера

На старом сервере нужно понять:

- где лежит рабочий проект Agent Second Brain;
- какие сервисы запущены через `systemd`;
- есть ли cron-задачи;
- где лежат данные Forumhouse/Барыги;
- какие папки занимают основной объём;
- какие файлы не попадают в git.

Команды для инвентаризации на сервере:

```bash
hostname
pwd
df -h
du -h -d 1 /home /root 2>/dev/null | sort -h
systemctl list-units --type=service --state=running
crontab -l
```

## Этап 2. Полная выгрузка на 37-й компьютер

Лучший базовый способ: `rsync` с сохранением структуры и возможностью продолжить при обрыве.

Запускать с 37-го компьютера:

```bash
rsync -aHAX --numeric-ids --info=progress2 --partial --delete user@server:/home/egor/agent-second-brain/ ./agent-second-brain/
```

Если проект лежит не в `/home/egor/agent-second-brain`, путь нужно заменить на реальный.

Для отдельных серверных данных:

```bash
rsync -aHAX --numeric-ids --info=progress2 --partial user@server:/root/forum-harvest/ ./forum-harvest/
```

## Этап 3. Проверка локальной копии

На 37-м компьютере после выгрузки проверить:

```bash
du -sh ./agent-second-brain
find ./agent-second-brain/vault -type f | wc -l
find ./agent-second-brain -name ".env" -o -name "*.service" -o -name "*.timer"
```

Минимально должно быть на месте:

- `vault`;
- `src`;
- `scripts`;
- `heartbeat`;
- `deploy`;
- `.env` или отдельная защищённая копия переменных окружения;
- проектные заметки;
- сессии и runtime-данные, если они нужны для продолжения работы.

## Этап 4. Подбор нового сервера

Критерии:

- заметно дешевле текущих 80-100 рублей в день;
- Ubuntu/Debian;
- стабильный SSH-доступ;
- достаточно диска под vault, логи и выгрузки;
- желательно возможность расширить диск;
- нормальная сеть для Telegram, OpenAI, Todoist, Deepgram и GitHub;
- понятная панель управления и возможность быстро переустановить систему.

Для бота без тяжёлых локальных моделей ориентир:

- 1-2 vCPU;
- 2-4 ГБ RAM;
- 30-80 ГБ SSD, в зависимости от объёма выгрузок;
- регулярные резервные копии либо возможность настроить свои.

## Этап 5. Перенос бота

На новом сервере:

```bash
git clone <repo-url> agent-second-brain
cd agent-second-brain
cp /path/to/saved/.env .env
```

Дальше восстановить зависимости, сервисы и автозапуск по актуальной инструкции проекта.

Перед переключением проверить:

- бот отвечает в Telegram;
- нет второго активного polling-клиента на том же токене;
- daily и vault пишутся в правильное место;
- Todoist доступен;
- OpenAI, Deepgram и остальные ключи работают;
- heartbeat и регулярная обработка запускаются;
- логи пишутся без ошибок.

## Этап 6. Отключение старого сервера

Старый сервер можно останавливать только после проверки:

- локальная копия на 37-м компьютере есть;
- новый сервер работает;
- бот отвечает;
- память и vault доступны;
- нужные данные Forumhouse/Барыги не потеряны;
- секреты и `.env` сохранены в защищённом месте.
