# Выгрузка видео

Общий инструмент для выгрузки сырья с YouTube-каналов и плейлистов в проектные папки.

## Что делает скрипт

- Забирает список роликов.
- Сохраняет метаданные и описание.
- Сохраняет комментарии, если YouTube отдаёт их через `yt-dlp`.
- Сохраняет субтитры и очищенный транскрипт.
- Может скачать видео и нарезать уникальные кадры по смене сцены.

## Скрипт

`scripts/выгрузка-видео.py`

## Пример для канала «Суровый Плотник»

```bash
python3 "vault/projects/Скрипт для выгрузки видео/scripts/выгрузка-видео.py" \
  --url "https://youtube.com/@suroviplotnik" \
  --output "vault/projects/dacha/Суровый Плотник" \
  --limit 5
```

С кадрами:

```bash
python3 "vault/projects/Скрипт для выгрузки видео/scripts/выгрузка-видео.py" \
  --url "https://youtube.com/@suroviplotnik" \
  --output "vault/projects/dacha/Суровый Плотник" \
  --limit 5 \
  --frames
```

По умолчанию видео используется как временный файл и удаляется после нарезки кадров. Чтобы сохранить файл видео рядом с карточкой ролика, добавь `--keep-video`.
