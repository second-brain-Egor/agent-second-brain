# Дача

Проект для всех мыслей, решений, набросков и рабочих материалов по даче.

## Как ведём

- входящие мысли сначала фиксируются сюда, без потери смысла
- дальше раскладываются по темам и превращаются в понятные блоки
- спорные идеи держим как варианты, не выдавая их за принятые решения
- долгие вопросы не превращаем в срочные задачи без явной команды

## Что уже понятно

- это отдельный проектный контейнер для дачи
- сюда будут приходить новые мысли прямо по ходу обсуждения
- задача контура: собирать, структурировать и держать проект в порядке
- проект ведётся в спокойном горизонте: без искусственного форсирования сроков

## Входящий поток

- сюда складывается сырой контекст до дальнейшей раскладки
- на участке есть навес; после зимы он частично разрушился
- под навесом лежит материал: доска `100x50` и `150x50`
- позже будет передан отдельный список закупок для учёта материалов
- на участке уже есть бытовка
- участок начинают постепенно обживать: нужно организовать санузел и душевую
- место для ночёвки уже есть
- первоочередное строение на участке: баня
- баня планируется на сваях
- после бани планируется беседка в стиле timberframe
- сейчас навес занят материалом; по мере расхода материала на баню будет освобождаться место под брус
- под баню уже завезены утеплитель и стеклопакеты

## Направления

### Участок и общая концепция

- участок уже используется как база для постепенного обживания
- текущая логика освоения: сначала обеспечить базовые бытовые условия, затем двигаться по основным строениям
- навес пока выполняет роль временного склада материалов, но требует внимания после зимних повреждений
- стартовая зона расчистки: левый дальний угол участка
- зону под баню рассматриваем как временную точку складирования собранной грязи и мусора до окончательного вывоза

### Строения и помещения

- на участке есть бытовка
- есть навес для хранения материала
- основное ближайшее строение: баня на сваях
- следующее крупное строение после бани: беседка в стиле timberframe
- до основных строений нужен временный бытовой контур: душевая, туалет, санузел
- на свайном поле под беседку может появиться временная бытовочка под кухню

### Инженерия и коммуникации

- для нормального обживания участка потребуется санузел
- также потребуется душевая
- ночёвка уже закрыта текущими условиями, это не первичный дефицит
- бытовой блок рассматривается как промежуточный шаг до разворота основных строений

### Материалы, техника и закупки

- под навесом хранится доска `100x50`
- под навесом хранится доска `150x50`
- зафиксирован отдельный учет купленного материала для бани: пиломатериал 356 шт., 2136 пог. м, 11.01 м³, плюс ОСП 9 мм — 23 листа
- для бани уже есть утеплитель
- для бани уже есть стеклопакеты
- ожидается отдельное пополнение списка закупок и остатков по материалам
- по бане висят две закупочные задачи: печь и плиты Quick Deck
- печь нужно смотреть через поездку на строительный рынок, затем заказать подходящую модель
- Quick Deck нужно смотреть напрямую на производстве: возможна покупка некондиции по сниженной цене, отдельно согласовать доставку
- под будущую обработку бруса закладывается работа с длинномером
- станок для обработки бруса планируется на рельсах `SBR20`
- появилась отдельная заметка по замене двигателя садового измельчителя `Kettama MPS02D`

### Решения и договорённости

- первостепенный проект на участке: баня
- материал под навесом рассматривается как ресурс для строительства бани
- освобождение места под будущий брус будет происходить естественно, по мере расхода текущего материала
- учёт материалов нужно вести отдельно и дополнять по мере передачи списка закупок
- свайные поля планируются отдельно под баню и под беседку timberframe
- зона под беседку рассматривается не только как будущее строение, но и как возможная временная база под кухню и часть мастерской

### Последовательность работ

- сначала освободить левый дальний угол участка и вычистить оттуда грязь
- в зоне будущей бани постелить геотекстиль либо плитный материал
- временно сложить на это место собранный мусор и грязь
- после первичной расчистки сделать душевую, туалет и санузел
- затем вывезти собранную грязь и мусор с участка
- после этого закрутить свайное поле под баню
- отдельно закрутить свайное поле под беседку timberframe
- на оголовках свайного поля под беседку можно собрать временную бытовочку под кухню
- дальше подтянуть из гаража кухню, станки и организовать зону хранения и работы
- по мере разворота мастерской предусмотреть место под обработку длинных деталей и бруса на станке с рельсами `SBR20`

### Закупочные задачи

- [ ] Съездить на строительный рынок за банной печью, выбрать подходящий вариант и заказать печь
- [ ] Съездить на производство Quick Deck, проверить наличие некондиции по сниженной цене и заказать доставку

### Вопросы и варианты

- в каком формате вести материальный учёт: просто перечень закупок, остатки или отдельный реестр движения материалов
- что делать с навесом: ремонт, усиление или замена конструкции
- в какой последовательности решать бытовой блок: временный санузел/душ или сразу в составе отдельного решения по участку
