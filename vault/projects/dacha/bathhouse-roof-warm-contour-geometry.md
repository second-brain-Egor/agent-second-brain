# Баня — кровля по тёплому контуру

Односкатная кровля. Конёк на одном краю, скат уходит вниз по всей глубине тёплого контура.

## База

- Габарит здания по ростверку: **9000 × 4400 мм** (9 м длина × 4,4 м глубина)
- Кровля считается односкатной
- Веранда пока не учитывается — отдельно

## Зафиксированный вариант (тёплый контур)

- Горизонт ската: **4,4 м** (от стены до стены)
- Подъём конька над нижним краем: **1,37 м**
- Угол ската: tan = 1,37 / 4,4 = 0,311 → **17,3°** (рабочий диапазон)
- Длина стропила по тёплому контуру, без свеса: √(4,4² + 1,37²) = **4,61 м**
- Свес: **0,4 м** по тому же углу → +0,4 / cos 17,3° ≈ **0,42 м** к длине
- Стропило со свесом: ≈ **5,03 м**

## Площадь ската (тёплый контур)

- Боковые свесы по торцам: **0,4 м** с каждой стороны → ширина ската 9,0 → **9,8 м**
- Без свесов: 9 × 4,61 = **41,5 м²**
- С нижним свесом: 9 × 5,03 = **45,3 м²**
- Со всеми свесами (нижний + боковые): 9,8 × 5,03 = **49,3 м²**

## Веранда (продолжение того же ската)

- Вылет веранды по горизонтали: **2 м** от нижнего свеса тёплого контура
- Угол сохраняем тот же: **17,3°**
- Длина ската над верандой: 2 / cos 17,3° = 2 / 0,955 = **2,09 м**
- Дополнительный сброс высоты: 2 × tan 17,3° = **0,62 м** (край над верандой опускается ещё на 62 см ниже нижнего свеса тёплого контура)
- Площадь над верандой по тёплому контуру (9 м): 9 × 2,09 = **18,8 м²**
- Площадь над верандой с боковыми свесами (9,8 м): 9,8 × 2,09 = **20,5 м²**

### Вся кровля одним скатом (тёплый контур + веранда), со всеми свесами

49,3 + 20,5 = **69,8 м²**

## Открытые вопросы

- Веранда: учитывать отдельно, на тёплый контур не влияет
- Если скат пойдёт только по части глубины — высоты пересчитать
