# Водосточная система (дача)

Заказывается **металл** (в исходном прайсе у поставщика был ПВХ — не наш вариант).
Прайс прислан поставщиком с опечатками; ниже расшифровка позиций.

## Спецификация (по присланному списку)

| № | Позиция |
|---|---------|
| 1 | Жёлоб 3 м |
| 2 | Соединитель жёлоба |
| 3 | Кольцо 72-45 |
| 4 | Воронка |
| 5 | Труба 3 м |
| 6 | Хомут трубы |
| 7 | Шпилька хомута |
| 8 | Наконечник |
| 9 | Заглушка |
| 10 | Кронштейн жёлоба |
| 11 | Цвет RAL 7024 (серый) |

Поставщик просил указать, сколько нужно **трёхметровых** и **двухметровых** элементов.

## Конфигурация кровли под слив

- 2 ската по **10 м** длины каждый
- Считаем два варианта: слив с одной стороны каждого ската и с двух сторон каждого.

## Открыто

- Актуальные рыночные цены на металлический водосток (запросить / прошерстить).
- Финальный подсчёт количества жёлоба, труб, кронштейнов под выбранную схему слива.
- Грамотный текст запроса поставщику с разбивкой на 3 м и 2 м элементы.
