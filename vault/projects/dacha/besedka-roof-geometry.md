# Беседка — кровля

Двускатная, фронтоны не зашиваются. Связано с [[bathhouse-roof-warm-contour-geometry|кровлей бани]].

## База

- Габарит беседки: **3,7 × 6 м**
- Конёк по длинной стороне (6 м), скаты вниз по ширине 3,7 м
- Половина ширины на скат: 3,7 / 2 = **1,85 м** горизонтали
- Свесы: **0,4 м** со всех сторон
- Угол ската: **45°** к горизонту (рабочее допущение, см. ниже)

## Расчёт (угол ската 45°)

- Горизонталь ската со свесом: 1,85 + 0,4 = **2,25 м**
- Длина ската по плоскости: 2,25 / cos 45° = 2,25 × 1,414 = **3,18 м**
- Длина конька со свесами по торцам: 6 + 0,4 + 0,4 = **6,8 м**
- Площадь одного ската: 6,8 × 3,18 = **21,6 м²**
- **Оба ската: ≈ 43,3 м²**

## Открытый вопрос по углу

Формулировки в записи две: «угол под 45 градусов» и «между скатами 45 градусов».

- Если **45° — это уклон каждого ската** (принято выше) → ≈ 43,3 м².
- Если **45° — это угол в коньке между скатами**, уклон каждого ската становится 67,5° (почти вертикаль), площадь ≈ 80 м². Маловероятно для беседки.

Взял первый вариант. Если имелся в виду угол в коньке — пересчитать.

## Вариант 2026-06-30

Если считать двускатную крышу как равнобедренный треугольник:

- Расстояние между крайними точками свеса: **3,7 м**
- Высота конька над горизонтом свесов: **1,5 м**
- Половина пролёта на один скат: 3,7 / 2 = **1,85 м**
- Угол ската: arctan(1,5 / 1,85) = **≈ 39,0°**
- Длина ската без дополнительного свеса: √(1,85² + 1,5²) = **≈ 2,38 м**
- В американской записи уклона это **≈ 9,7:12**, почти **10:12**

Справка по американским уклонам:

| Уклон | Угол |
|---|---:|
| 8:12 | 33,7° |
| 10:12 | 39,8° |
| 11:12 | 42,5° |
