# Kettama MPS02D — замена двигателя

Короткая рабочая заметка по садовому измельчителю `Kettama MPS02D`: что удалось выяснить по двигателю, аналогам и экономике замены.

## Подтверждённые параметры модели

- `230 В`
- `2500 Вт`
- `4500 об/мин`
- ветки до `45 мм`

Источник по модели: инструкция `Kettama MPS02D`.

## Что удалось выяснить по моторной платформе

- в открытом доступе не найден подтверждённый артикул родного двигателя `Kettama MPS02D`
- по косвенным признакам это типовая китайская щёточная платформа с ременным приводом
- у близкого аналога `NAC SHE250B-BAG-LD2` совпадает класс: `230 В`, `2500 Вт`, `4500 об/мин`, `45 мм`
- для этой платформы встречаются такие ориентиры по узлам:
- щётки `7x14x20 мм`
- ремень `10PJ375`
- шкив ротора `YT5455 / SHE250B-BAG-LD2` с отверстием под вал `8 мм`, длиной `31 мм`, шириной `18 мм`, `11` ручьёв

## На что смотреть при подборе аналога

- тип двигателя: щёточный, с ременным приводом
- диаметр и длина вала
- посадка шкива
- крепёжные отверстия и габариты корпуса
- совместимость по ремню и расположению узлов

Покупать двигатель только по мощности нельзя: критична механическая совместимость.

## Возможные ориентиры по аналогам

- `NAC SHE250B-BAG-LD2`
- `NAC YT5455`
- `ER2400 / ERH2400`
- некоторые модели `Lider / Handy / Faworyt` той же платформы

Практический поисковый ориентир:
`двигатель в сборе для измельчителя SHE250B / YT5455 / ER2400 / 10PJ375 / вал 8 мм`

## Экономика ремонта

- дорогой брендовый мотор уровня `STIHL / VIKING 60086000216` для этого сценария не выглядит рациональной покупкой
- по здравому смыслу и рынку такой вариант может стоить как весь измельчитель или дороже
- для `Kettama MPS02D` разумнее сначала исключать недорогие неисправности: щётки, термозащиту, проводку, ремень, шкив
- если реально сгорели якорь и статор, чаще выгоднее искать донорский узел или донорский измельчитель той же платформы, чем покупать дорогой отдельный мотор

## Ориентиры по ценам в рублях

- щётки двигателя: примерно `250-500 ₽`
- шкив: примерно `700-900 ₽`
- недорогой ремонт по мелочам, если проблема в щётках, ремне, шкиве, термозащите или проводке: обычно около `500-3000 ₽`
- двигатель в сборе из найденных аналогов: ориентир порядка `10000-11000 ₽`
- дорогой европейский аналог: ориентир порядка `22000-23000 ₽`

Практический вывод по деньгам:
- дешёвый ремонт имеет смысл
- замена мотора целиком уже погранична по выгоде
- дорогой отдельный мотор для такого измельчителя обычно нерационален

## Текущий вывод

Надёжного подтверждённого аналога, который можно честно назвать заменой без переделок именно для `Kettama MPS02D`, пока нет.

Рабочая гипотеза:
- искать донор или моторный узел той же платформы
- ориентироваться на вал `8 мм`, ремень `10PJ375`, щёточный двигатель `230 В / 2500 Вт / 4500 об/мин`
- окончательный подбор делать только после сверки снятого мотора по валу, креплению и корпусу
