## Аналитическая сводка

### Общий вывод

Все три ролика пригодны для базы по каркасной бане, но ценность разная.

Самый полезный технически: 003, расширенная версия гостевого дома 40 м² по СП 31-105-2002.

Самый полезный как короткий референс по объекту близкого размера: 002, гостевой дом 40 м² за 19 дней.

Первый ролик полезен как общий пример быстрого монтажа более крупного каркасного дома 62 м² и как источник большого списка материалов.

### Повторяющиеся решения

- Свайное основание с отсечной гидроизоляцией по оголовкам.
- Деревянный ростверк, крепление к оголовкам конструкционными шурупами 8х120 с прессшайбой.
- Платформа пола из шпунтованного ОСП 18 мм.
- Каркас из доски 50 мм.
- Сборка стен на платформе с последующим подъемом.
- Супердиффузионная мембрана по стенам/перекрытию.
- Проклейка мембран специализированными лентами.
- Кровля: ОСП, подкладочный ковер, карнизные/торцевые планки, битумная черепица, коньковая вентиляция.

### Важно для проекта бани

- Для свайного основания нужно заранее думать не только о диаметре свай, но и о доступе снизу. В комментариях автор прямо говорит про комфортную высоту 50-60 см для утепления пола снизу.
- Утепление пола автор предпочитает делать после кровли, чтобы не намочить утеплитель до закрытия контура.
- Сетка от грызунов и ветровлагозащита пола в этой логике ставятся снизу после утепления.
- Для ОСП 1250х2500 в комментариях подтвержден шаг 625 мм.
- По кровле автор не считает обязательной отдельную обрешетку под ОСП, если ОСП уложено правильно и нужной толщины.
- По воде на временно открытом ОСП автор использует дренажные отверстия, затем после кровли закрывает их скотчем.
