# Японская архитектура

Отдельный проект для базы знаний по традиционной японской архитектуре.

## Главный принцип

Проект не смешивается с timberframe.

Связи и пересечения возможны, но материалы, каталог, заметки и выводы по японскому домостроению ведутся отдельно. Timberframe остаётся отдельным направлением.

## Цель проекта

Собрать самостоятельную базу знаний по японской архитектуре:

- источники
- сайты и справочные страницы
- книги
- изображения
- схемы и чертежи
- видео
- заметки
- тематическую структуру

База собирается независимо от будущего использования.

## Как использовать базу

Основной режим — личный справочник для изучения:

- устройство японского дома
- кровли
- столярные соединения
- планировки
- сады
- материалы
- пропорции
- логика пространства
- детали интерьера

Дополнительный режим — источник для будущих медиа-проектов:

- посты
- Telegram-канал
- YouTube-ролики
- анимированные разборы
- визуальные схемы

Медиа-формат не управляет сбором базы. Сначала создаётся чистая база, потом из неё можно брать проверенный материал.

## Порядок работы

1. Сначала собрать чистый каталог источников.
2. Разложить источники по темам и типам материалов.
3. Убрать дубли и мусор.
4. Отметить, что в каждом источнике полезного.
5. Сохранять указатели и метаданные для видео, изображений, PDF и внешних материалов.
6. Глубокую загрузку делать постепенно, по приоритетам.
7. Не превращать проект в свалку медиафайлов без навигации.

## Правила каталога

Каталог должен отвечать на вопросы:

- где источник
- к какой теме он относится
- какой это тип материала
- что в нём ценно
- стоит ли возвращаться к нему глубже
- есть ли локально сохранённые материалы

## Медиафайлы

Видео, изображения, PDF и другие материалы подтягиваются постепенно.

Сначала важнее сохранить структуру, ссылки, описания и приоритеты. Полная выгрузка внешних материалов делается только там, где источник действительно ценен.
