# Структура презентации

## Слайд 1. Название

Внедрение ИИ на предприятии: закрытый цифровой контур для работы с информацией.

## Слайд 2. Главная рамка

ИИ — инструмент для сбора, обработки и предоставления информации.

ИИ не является руководителем, ответственным лицом, самостоятельным участником управления или заменой специалиста.

## Слайд 3. Проблема

Информация предприятия разрознена: документы, схемы, регламенты, фото, отчеты, справочники и опыт сотрудников находятся в разных местах.

## Слайд 4. Решение

Создать закрытый цифровой контур, который объединяет данные предприятия и дает быстрый доступ к ним через локальные ИИ-инструменты.

## Слайд 5. Инициативы

Инфраструктура, база знаний, документы, аварийное реагирование, обучение, аналитика, безопасность, организационное внедрение.

## Слайд 6. Практические сценарии

Поиск по регламентам, подготовка материалов, учебные сценарии, анализ отчетов, справочник по объекту, поддержка работы с пожарной сигнализацией.

## Слайд 7. Безопасность

Локальное размещение, контроль доступа, журналирование, разграничение прав, проверка источников.

## Слайд 8. Этапы

Рамка проекта, инвентаризация данных, технический контур, пилот, проверка качества, расширение, эксплуатация.

## Слайд 9. Ожидаемый результат

Предприятие получает инструмент, который ускоряет работу с внутренней информацией и повышает доступность накопленных знаний.
