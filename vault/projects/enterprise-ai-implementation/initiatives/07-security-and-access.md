# Безопасность, доступы и конфиденциальная информация

## Цель

Задать правила безопасной работы с внутренними данными предприятия в ИИ-контуре.

## Состав

- разграничение прав доступа
- закрытое хранение данных
- журналирование запросов и действий
- правила работы с чувствительной информацией
- запрет передачи данных во внешние сервисы
- порядок обновления и удаления данных

## Результат

Понятная модель безопасности, без которой проект нельзя переводить в промышленную эксплуатацию.
