# Алгоритмы и логика

## Слой 1. Голос → текст

Локальная нейросеть распознавания речи (Vosk или Whisper). Выход — текстовая строка с командой/запросом руководителя.

## Слой 2. Текст → пункт справочника

Классические алгоритмы, без нейросетей. Работают мгновенно, весят мало, понятны.

### Справочник оборудования

Структурированная база: оборудование, помещения, лучи сигнализации, отсечки, маршруты, техника. Заранее загружена в приложение.

### Словарь синонимов

Простой файл соответствий: «насос» = «помпа», «агрегат», «ГА». При поиске проверяются все варианты.

### Нечёткий поиск (расстояние Левенштейна)

Ловит опечатки распознавания. «Давлиение» → находит «давление». Готовая библиотека для Android.

### Стемминг

Сводит окончания к корню: «насосы», «насоса», «насосом» → «насос». Готовые офлайн-библиотеки для русского.

## Слой 3. Логика рекомендаций

Алгоритм расстановки техники и подсказок по обстановке. Пока на стадии формулирования.

Что нужно описать (открытые вопросы):
- какие сценарии аварии охватываем в первую очередь
- какие типы техники и оборудования включаем в справочник
- по каким признакам подбираем рекомендации (тип аварии, место, ветер, доступность техники)
- формат вывода: один вариант или несколько с пояснениями

## Что НЕ используем

- большие языковые модели
- облачные сервисы
- сетевые API
- любые алгоритмы, требующие интернет

## Архитектурный принцип

Двухслойность: маленькая нейросеть только для распознавания речи, дальше — детерминированная логика на справочниках. Это даёт предсказуемость, проверяемость и независимость от сети.
