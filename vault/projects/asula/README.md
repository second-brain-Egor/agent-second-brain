# АСУЛА

Автоматизированная Система Управления Ликвидацией Аварии. Помощник руководителю работ и диспетчеру при ликвидации аварии на опасном производственном объекте.

## Суть

Локальное офлайн-приложение на планшете, которое в момент аварии:
- даёт полную информацию по объекту (оборудование, помещения, лучи сигнализации, отсечки)
- помогает принять решение по расстановке сил и средств
- сокращает время поиска данных и ошибки от спешки

Главный принцип: всё работает на устройстве, без интернета, без облака, в закрытом контуре предприятия.

## Где живёт

АСУЛА — одно из направлений общего проекта **«Цифровой контур предприятия»** (закрытая интеллектуальная среда нефтезавода без выхода в интернет). Конкретно АСУЛА закрывает направление «аварийная готовность и реагирование».
