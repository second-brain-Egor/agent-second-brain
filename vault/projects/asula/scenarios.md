# Сценарии

## 1. Пожарная сигнализация (зафиксировано 2026-04-28)

При выборе луча система последовательно показывает:

1. где установлен пульт пожарной сигнализации (помещение, здание)
2. какой луч идёт в это здание
3. какие помещения и зоны защищает выбранный луч
4. сопутствующая информация по защищаемому оборудованию

Цель: руководитель за один клик/голосовую команду видит полную картину по выбранному лучу, без хождения по схемам и журналам.

## 2. Расстановка сил и средств (черновик)

При вводе типа аварии и места система предлагает варианты:
- какую технику задействовать
- куда подвести
- с учётом направления ветра, расположения оборудования, маршрутов
- варианты боевого развёртывания

Алгоритм опирается на справочник оборудования и шаблоны типовых сценариев. Подробнее — [[algorithms.md]].

## 3. Информация для принятия решений (из черновика 2026-05-09)

Помощник в момент выезда/реагирования по запросу даёт:
- место использования техники, направление ветра, место выезда
- оборудование и продукция в зоне
- состояние систем (ПТЗ, НППА и пр.)
- готовность работников к выполнению задачи
- маршрут сопровождения

## 4. Сценарии к проработке

- работы повышенной опасности (наряд-допуск, соответствие схемы)
- позиционирование без GPS (по фото и опорным точкам)
- обходы и диагностика
