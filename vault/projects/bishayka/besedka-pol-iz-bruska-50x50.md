# Пол беседки из бруска 50×50

Проект: [[README|Бишайка]]. К даче не относится.

Площадь пола — 2,5×3,8 м, то есть 9,5 м². Рассматривается настил из обработанного бруска 50×50 мм с зазором 2–3 мм вместо террасной доски по 2 700 ₽/м².

## Расчёт

- Нужно примерно 179–183 пог. м бруска.
- Чистый объём — 0,448–0,457 м³.
- При цене 23 000 ₽/м³ — около 10 300–10 500 ₽ без запаса.
- С запасом 10% на отбор и торцовку — около 0,50 м³, или 11 500 ₽.
- 64 бруска 50×50×3000 мм дают 192 пог. м и 0,48 м³ — этого хватает на расчётный объём настила.
- Террасная доска на ту же площадь — 25 650 ₽ без запаса.

## Конструкция

- В продаже брусок 50×50 мм есть только длиной 3 м.
- Принятый шаг лаг — 600 мм; раскрой нужно вести так, чтобы каждый стык бруска приходился на лагу.
- Для улицы предпочтительны коррозионностойкие террасные саморезы; крепить с предварительным засверливанием, особенно у торцов.
- Брусок обработать со всех сторон, а торцы защитить отдельно; зазор 2–3 мм оставить для стока и сезонного движения древесины.
