# Приложение по дорогам

Офлайн-карта предприятия для Android. Без интернета и GPS. Пользователь может вручную помечать дороги перекрытыми, приложение пересчитывает маршрут в обход.

## Идея

Две сущности:
- **Подложка** — план предприятия (картинка или SVG-вектор).
- **Граф дорог** — узлы (перекрёстки) и рёбра (отрезки дорог с длиной) поверх подложки.

Пользователь тапает по ребру → оно перекрыто (вес = бесконечность). Маршрут считается через Dijkstra или A*.

## Источник схемы

- В наличии: карта в Visio и карта в PDF.
- Решение: брать Visio как источник, экспортировать в SVG (File → Save As → SVG). PDF — резерв.

## Стек

- **Язык/UI:** Kotlin + Jetpack Compose.
- **Карта:** Canvas-отрисовка поверх SVG-подложки (osmdroid/MapLibre — опция, если территория большая).
- **Граф и алгоритм:** отдельный модуль на Kotlin, без привязки к Android.
- **Хранение:** локальный JSON + локальное состояние перекрытий.

## Формат графа

```json
{
  "nodes": [{"id": 1, "x": 120, "y": 340}],
  "edges": [{"from": 1, "to": 2, "len": 42.5}]
}
```

Координаты — внутренние пиксели SVG, без широт-долгот.

## План работы

1. Поставить Android Studio, создать пустой проект Kotlin + Compose.
2. Экран с подложкой: зум, перетаскивание.
3. JSON с узлами и рёбрами, отрисовка поверх картинки.
4. Тап по ребру → переключение перекрыто/открыто.
5. Выбор точки старта и финиша.
6. Алгоритм поиска маршрута, рисование пути линией.
7. Локальное сохранение состояния перекрытий.

## Разделение работы

**На агенте:**
- Python-скрипт чистки SVG (оставить только слой дорог).
- Парсер SVG → `graph.json` (склейка близких концов в узлы, расчёт длин).
- HTML-проверялка графа поверх схемы.
- Модуль маршрутизации на Kotlin (Dijkstra/A*, пометка перекрытий) — изолированный, тестируется отдельно.
- Скелет Android-приложения: подложка, зум, отрисовка графа, тап по ребру, выбор старта/финиша, отрисовка маршрута, локальное хранилище.

**На пользователе:**
- Сама схема предприятия (исходник Visio).
- Решение, какие линии считать дорогами.
- Установка Android Studio.
