# VPN

## Обсуждение 13 октября 2026

Исходные условия и границы проекта — [[memory/facts#2026-10-13 — WireGuard и чтение банковских сайтов]].

- По словам Егора, после установки профиля подключение не работает. Раньше он включал прокси и вводил адрес, после чего связь появлялась.
- Прежние адрес и порт прокси пока не восстановлены. Наличие работающего прокси на стороне сервера не проверено; неисправность туннеля отдельно не локализована.
- Обычная схема WireGuard из первого ответа не объяснила прежнюю конфигурацию Егора. В чате обсуждалась возможная связка туннеля и прокси; это гипотеза, а не установленная архитектура.
