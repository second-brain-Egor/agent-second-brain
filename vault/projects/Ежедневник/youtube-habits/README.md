# Разбор YouTube-видео про привычки

Здесь будет разбор видео про привычки для дальнейшего планирования ежедневника.

## Черновая выгрузка

- Видео: 5. Привычки успешных людей. Брайан Трейси
- Ссылка: https://www.youtube.com/watch?v=KcRnotna5qY
- Канал: Андрей Кабо
- Папка: videos/001-5-привычки-успешных-людей-брайан-трейси
- Статус: сырьё выгружено, глубокий разбор отложен

## На будущее

- На канале есть другие полезные ролики; позже стоит разобрать канал отдельной пачкой.

## Что нужно получить из видео

- Ключевые идеи по формированию привычек.
- Практические правила, которые можно встроить в ежедневник.
- Примеры триггеров: когда / где / что.
- Что подходит для смены.
- Что подходит для дня после смены.
- Что подходит для рабочего выходного.
- Что подходит для свободного дня.
- Какие формулировки привычек лучше использовать.
- Какие ошибки не переносить в ежедневник.

## Контур обработки

Используется общий скрипт:

```bash
python3 "vault/projects/Скрипт для выгрузки видео/scripts/выгрузка-видео.py" \
  --url "ССЫЛКА_НА_YOUTUBE" \
  --output "vault/projects/Ежедневник/youtube-habits"
```

После выгрузки нужно сохранить:

- метаданные;
- описание;
- транскрипт;
- при необходимости комментарии;
- итоговый анализ для планирования.
