# Ежедневник

Проект для личного ежедневника под график сутки через трое, привычки и распределение задач внутри дня.

## Цель

Сделать ежедневник, который помогает не просто хранить список дел, а раскладывать день по энергии, типу дня и доступным временным блокам.

## Основные принципы

- Сначала тип дня и энергия, потом задачи.
- На день один главный фокус.
- Обязательных дел немного: 1-3 пункта.
- Привычки идут отдельным коротким блоком, без превращения в долг.
- Смена не нагружается крупными личными задачами.
- Первый день после смены считается восстановительным.
- Самые тяжелые задачи ставятся на рабочий выходной.
- Свободный день держится как буфер, планирование и спокойное закрытие хвостов.

## Типы дней при смене 5 мая 2026

- 2026-05-05: смена.
- 2026-05-06: после смены, восстановление.
- 2026-05-07: рабочий выходной.
- 2026-05-08: свободный день / буфер.
- 2026-05-09: следующая смена.

## Что уже принято в шаблон

- Таймбоксинг: задаче назначается место в дне, а не просто строка в списке.
- Implementation intentions: привычка формулируется как "когда-где-что".
- Минимальный вариант привычки должен быть настолько маленьким, чтобы его можно было сделать даже в плохой день.
