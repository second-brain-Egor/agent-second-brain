# Журнал документов — Ирина работа

## Структура папки

- `Стандарты фирменного стиля.pdf` — лежит в корне, общий для всех подпроектов.
- `Журнал документов.md` — этот журнал.
- `Приводи своих друзей/` — подпроект по акции Россельхозбанка «Приводи своих друзей» (реферальная программа).
- `.служебное/` — скрытые папки рядом с документами (в корне и в подпроекте) с извлечённым текстом и метаданными бота. Руками не трогать.

Порядок: документ, общий для всей работы Ирины, кладётся в корень, документ по конкретной задаче — в папку её подпроекта. Если текущий проект и подпроект уже понятны из беседы, бот сохраняет туда файл без повторного вопроса; помощник проверяет размещение при следующем сообщении и уточняет только при сомнении. Без текущего проекта бот предлагает последние проекты и «Все проекты»; при выборе этой корневой папки — подпроекты, «В корень», «Новый подпроект». После сохранения называет путь и добавляет строку в раздел «Записи». Остальные действия с документами тоже записывать строкой в «Записи». Общий порядок — [[thoughts/learnings/документы-и-проекты-в-боте]].
