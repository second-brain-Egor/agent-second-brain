# TimberFrame

Отдельный проект по направлению timberframe.

## Контекст

Это не только мастерская и оборудование, а весь долгий контур: технология, производство, будущие объекты и развитие своего дела.

## Что входит

- мастерская и оборудование для обработки бруса
- геометрия и технология соединений
- баня, беседка и другие будущие объекты
- производственный контур под timberframe
