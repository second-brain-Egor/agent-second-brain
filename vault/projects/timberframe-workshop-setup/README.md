# Timberframe Workshop Setup

## Текущее оборудование

Рейсмус **Билмаш** — обрабатывающая голова на 4 опорах. Голова регулируется сверху через цепной привод (аналог DeWalt 735). Важно: выбран именно цепной привод (не червячная передача), потому что планируется убрать дно и поставить голову на направляющие.

## План кастомизации

1. **Рейсмус на рельсах** — голова Билмаш устанавливается на направляющие **SBR20** на каретках. Двигается вдоль бруса (до 6 м) для обработки поверхности.

2. **ЧПУ портал (будущее)** — после обработки рейсмусом, по брусу едет портал с фрезерным шпинделем на рейке (ШВП не подходит для 6 м). 3-координатное ЧПУ для вырезания пазов и шипов.

3. **Геометрия соединений** — для timberframe нужна идеальная геометрия бруса. Шипы/пазы: либо квадратные (дорезать стамеской), либо полукруглые (фреза).
