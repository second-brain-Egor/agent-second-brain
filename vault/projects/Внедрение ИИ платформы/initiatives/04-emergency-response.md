# Аварийное реагирование и поддержка решений

## Цель

Создать информационную поддержку для подготовки, обучения, анализа сценариев и быстрого поиска нужных сведений при работе с аварийной тематикой.

## Возможности

- быстрый доступ к регламентам и схемам
- подготовка карточек сценариев
- анализ вводных для учений
- поиск по материалам аварийной готовности
- сопоставление данных по объекту, зонам и оборудованию

## Ограничение

ИИ не отдает распоряжения и не выбирает тактику действий. Он предоставляет информацию для человека.
