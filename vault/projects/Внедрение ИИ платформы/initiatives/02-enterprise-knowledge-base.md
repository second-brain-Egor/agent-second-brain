# База знаний предприятия

## Цель

Собрать внутренние знания предприятия в единую структуру, пригодную для поиска, анализа и использования ИИ-инструментами.

## Источники

- регламенты
- инструкции
- схемы
- фото объекта
- справочники
- отчеты
- журналы
- материалы обучения
- практический опыт специалистов

## Результат

Единая база знаний, которая становится основой для документов, обучения, аналитики, аварийной готовности и прикладных сценариев.
