# Карточка ролика: бесплатные модели OpenRouter внутри Claude Code

Дата: 2026-08-21  
Длительность: 13:34  
Ссылка: https://www.youtube.com/watch?v=_kK_4cOYF4o

## Кратко

Автор подключает бесплатные модели OpenRouter к оболочке Claude Code через переменные окружения. Модели умеют пользоваться файлами, навыками и инструментами Claude Code, но в тестах работают намного медленнее Claude и чаще падают по тайм-ауту.

## Схема настройки из ролика

1. Создать ключ API в OpenRouter.
2. Работать через терминал, VS Code или расширение Claude Code: настольное приложение, по словам автора, переопределяет эти настройки.
3. В файле настроек Claude Code указать базовый адрес OpenRouter, ключ вместо токена Anthropic и идентификатор модели во всех слотах моделей.
4. Открыть новую сессию и проверить отображаемую модель.
5. Для нестабильной бесплатной модели дробить работу на небольшие части.

Автор тестировал `stealth/ox-alpha`, а также упоминает бесплатный маршрутизатор OpenRouter и возможность заменить идентификатор на другую модель.

## Результаты тестов автора

- Лендинг с рабочей корзиной и фирменным стилем был создан примерно за 6 часов.
- Аналитический отчёт по YouTube с таблицей также занял около 6 часов; Claude, по оценке автора, сделал бы это за 20–30 минут.
- Простая обработка ролика зависла и завершилась блокировкой примерно через 45 минут.
- Анализ обращений сообщества занял около 25 минут.
- Бесплатная модель смогла читать проектные инструкции, запускать навыки, искать файлы и пользоваться инструментами оболочки.

## Вывод автора

Бесплатные и небольшие модели подходят для лёгкой работы со знаниями и как запасной вариант при исчерпанном лимите. Для разработки, сложного планирования и оркестрации множества агентов заметно лучше сильные платные модели.

## Практическая ценность для Егора

Для Agent Second Brain это возможный дешёвый резервный контур: классификация, простые сводки и фоновая обработка без чувствительных данных. Основной агентный цикл и сложные изменения проекта лучше не переносить туда без отдельного теста качества и времени выполнения.

## Ограничения и проверка

- «Бесплатно» не означает нулевую стоимость всегда: автор увидел около 0,13 доллара расхода после 61,6 млн токенов.
- Бесплатные модели и тарифы OpenRouter меняются; конкретное имя и доступность надо проверять перед настройкой.
- Анонимный поставщик модели создаёт риск конфиденциальности. Чувствительные данные передавать ему не следует.
- Числа времени — единичные опыты автора, а не воспроизводимый тест.
