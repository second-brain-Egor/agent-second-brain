## @jakub_mika

Playwright is a deterministic script framework where you code exact selectors and steps up front, and it only fails or drifts when the page's HTML changes; Codex's browser use is an AI agent that looks at the screen with vision and reasons about where to click in real time, so it can handle messy, unpredictable UIs and "try to break things" without you writing any selectors. The tradeoff is that Codex is slower, costs more, and is less reliable for the same repeatable task, which is exactly why the video says to reach for a plain Playwright/macro script first and only use vision-based browser use when the flow genuinely needs eyes and judgment.
