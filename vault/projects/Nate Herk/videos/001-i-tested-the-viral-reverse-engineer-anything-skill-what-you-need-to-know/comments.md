## @Zuranthus

REA uses actual decompilers to read code instructions, that's why it takes longer but also produces better results, if you vibe it the model is just guessing, using REA it reads actual instructions, passes it to a tester and compares, if the results are not the same it decompiles again until it gets it exact, so you can recreate features faithfully with enough time. it's most impactful in things like device emulation, where exactness is a must, if you're just copying a feature then yeah, it doesn't have to be exact byte for byte like you would get from REA
