# Карточка ролика: DeepSeek Harness против Claude Code после недели тестов

Дата: 2026-08-23  
Длительность: 18:02  
Ссылка: https://www.youtube.com/watch?v=UsfCe5fJK6A

## Кратко

Нэйт неделю сравнивал открытый DeepSeek Harness с Claude Code. Его главный вывод: это не «бесплатный Claude Code», а отдельная, очень гибкая оболочка для агентов. На одинаковой модели она в его тестах выполняла задачи заметно быстрее, но пока уступала Claude Code по надёжности, глубине и качеству итоговых материалов.

## Основные идеи автора

- Оболочка и модель — разные уровни системы. Качество результата зависит не только от модели: цикл агента, инструменты, контекст и правила оболочки заметно меняют её поведение.
- DeepSeek Harness бесплатен и имеет открытый исходный код, но вызовы платных моделей через API оплачиваются отдельно.
- Главная особенность — архитектура «всё является плагином»: можно менять инструменты, навыки, сессии, хранилище, песочницу, агентный цикл и интерфейс.
- В стандартном режиме загружается проектный контекст и доступен полный набор инструментов. Минимальный режим быстрее, но рассчитан на простые разовые задачи без полного контекста.
- PTC-режим автор использовал для крупных параллельных задач; режим создателя — для разработки плагинов и изменения самой оболочки.
- Дешёвая цена токена не равна низкой цене готового результата: слабая модель или неэффективный цикл могут потратить больше времени и токенов.
- В текущем виде продукт ощущается как предварительная версия: автор столкнулся с ошибками интерфейса, сжатия контекста и длинных сессий.

## Показанная настройка и работа

1. Передать ссылку на репозиторий DeepSeek Harness агенту и попросить помочь с локальной установкой.
2. Открыть локальный интерфейс, перейти в настройки моделей и добавить ключ API, например OpenRouter.
3. Выбрать модель и режим работы под задачу.
4. Для коротких действий использовать минимальный режим; для полноценной работы с проектом — стандартный; для крупных параллельных задач — PTC.
5. Проверять сторонние плагины перед установкой: автор прямо предупреждает, что в открытом коде могут быть вредоносные действия.

## Результаты сравнений автора

- Поиск нужного транскрипта в большой базе знаний: около 50 секунд в DeepSeek Harness против более чем 5 минут в Claude Code на одной модели.
- Создание таблицы с аналитикой YouTube: примерно 3 минуты против 17 минут. Результат DeepSeek Harness был компактнее и нагляднее, но Claude Code дал более глубокую детализацию и больше данных.
- Исследование влияния сахара по одному навыку: Claude Code подготовил около 5000 слов и 26 источников; DeepSeek Harness — около 4400 слов и 14 ключевых источников. Автор счёл вариант Claude Code более глубоким, осторожным и надёжным.
- Навыки, созданные под Claude Code, обе оболочки интерпретировали по-разному. Автор предполагает, что отдельная адаптация навыка под DeepSeek Harness улучшит результат, но в ролике это не проверено.

## Практическая ценность для Егора

Для Agent Second Brain DeepSeek Harness интересен как экспериментальный резервный контур для быстрого поиска, фоновой обработки и дешёвых моделей. Переносить на него основной контур пока рано: сначала нужен изолированный тест на копии базы с одинаковыми заданиями, замером времени, стоимости, полноты источников и числа ошибок.

Отдельно полезна идея разделять качество модели и качество оболочки. При сравнении новых систем нужно фиксировать не только модель, но и загружаемый контекст, инструменты, навыки, режим работы и критерии готовности результата.

## Ограничения и что требует проверки

- Все цифры — личные тесты автора без опубликованной воспроизводимой методики; это не независимый бенчмарк.
- Сравнения проводились на навыках, изначально созданных под Claude Code, что могло дать ему преимущество в качестве.
- Утверждения о скорости, стоимости и доступных режимах относятся к версии продукта на дату ролика и могут быстро измениться.
- Автор сообщает о сбоях интерфейса, потере контекста и чрезмерно уверенных выводах. До работы с важными данными нужны песочница, проверка плагинов и контроль источников.

## Связи с базой

- Дополняет карточку о бесплатных моделях OpenRouter в Claude Code: дешёвая модель сама по себе не гарантирует дешёвое и качественное выполнение задачи.
- Связан с подходом Agent Second Brain к проектным инструкциям: один и тот же навык может вести себя по-разному в другой оболочке и нуждается в отдельной проверке.
