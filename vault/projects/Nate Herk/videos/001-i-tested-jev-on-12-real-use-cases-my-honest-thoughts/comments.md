## @kraayenjon

TL;DR 
The short version of what Jev is

- It's not a chat model. You send a state (text or JSON) plus typed
  questions, and it returns typed answers:
  - Choice: picks one option (up to 255)
  - Score: places the input on a scale you define
  - Noul: probability that a statement is true
- All questions in one call run in parallel. Answers in 70–500 ms.
- $0.042 per 1M input tokens. Output is free.
- Limits: 250k tokens/s, 1,200 req/min, 64k tokens per request, text only.
