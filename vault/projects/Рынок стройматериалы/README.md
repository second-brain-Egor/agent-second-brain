# Рынок стройматериалы

Отдельный проект по мониторингу рынков стройматериалов, сравнению цен, наличия, доставки и возможному приложению для закупок.

## Суть

Собрать рабочий контур, который помогает понимать, где выгоднее покупать стройматериалы: по рынкам, сайтам, актуальным ценам, наличию, количеству и доставке.

Идея шире одной стройки: это отдельный закупочный проект, который может применяться для разных задач и со временем вырасти в приложение с обновляемой информацией.

## Точки сравнения

- `Леруа Мерлен`
- `Новорязанка`
- стройрынок `Терем` в Анциферово

## Что уже известно

- `Рязанка` и `Новорязанка` здесь считаются одним и тем же рынком
- уже есть практический опыт: по части позиций `Новорязанка` оказалась дешевле даже с учётом доставки
- по `Новорязанке` интерес не только в разовой покупке, но и в получении актуальных цен, наличия и количества
- `Терем` — локальный строительный рынок в Анциферово, отдельная точка сравнения с сетевыми и крупными рыночными вариантами
- 2026-04-26 добавлена распознанная страница 1 прайс-листа со стройматериалами: позиции 1-40, сумма по странице 2 890 225 руб.
- 2026-04-26 добавлена распознанная страница 2 прайс-листа со стройматериалами: позиции 41-81, сумма по странице 1 650 340 руб.
- 2026-04-26 добавлена распознанная страница 3 прайс-листа со стройматериалами: позиции 82-101, сумма по странице 723 285 руб.
- 2026-04-26 по позициям 1-101 заведены карточки для приложения: Новорязанка как базовая цена, Терем и Леруа/Лемана ПРО как точки сравнения.
- Полный прайс Новорязанки обработан: 101 позиция на 5 263 850 руб.
- 2026-04-26 создан рабочий файл сравнения только по названию и цене: 101 базовая позиция, найдено 48 аналогов в Тереме и 22 аналога в Леруа/Лемана ПРО.
- 2026-04-28 повторно синхронизированы отдельные карточки товаров по Терему и Леруа/Лемана ПРО: 101 карточка на месте, найдено 48 аналогов в Тереме, 25 аналогов в Леруа/Лемана ПРО и 16 позиций во всех трёх точках; строк `не проверено` не осталось.
- 2026-04-26 перепроверены исходники полного прайса: по журналу действительно приходили две отправки по три фото, но из-за одинакового имени файла внутри одного Telegram-альбома страницы перезаписались; локально осталась только страница 2 из 3. Механизм сохранения вложений исправлен на будущее.

## Ценность проекта

- видеть реальную итоговую цену, а не только цену на ценнике
- сравнивать цену товара вместе с доставкой
- понимать наличие и объём, который можно купить сейчас
- выбирать точку закупки под конкретный набор материалов
- накапливать историю цен, чтобы видеть, где цена стабильнее или выгоднее
- рассмотреть совместные закупки с соседями по `СНТ`, чтобы снижать стоимость доставки

## Границы проекта

- это самостоятельный проект, не подпроект дачи
- дачные закупки могут быть одним из применений, но не определяют структуру проекта
- в центре проекта — рынки, цены, наличие, доставка, приложение и совместные закупки

## Возможная логика приложения

- карточка материала или товарной позиции
- цена по каждой торговой точке
- наличие и количество
- стоимость доставки
- итоговая цена с доставкой
- история изменения цены
- отметка, где выгоднее покупать
- группировка позиций под конкретную закупку или стройэтап
- сценарий коллективного заказа для `СНТ`
- источник цены и дата последнего обновления
- комментарий по качеству, доставке или условиям покупки

## Первые категории для мониторинга

- пиломатериалы
- крепёж
- гидроизоляция и мембраны
- кровельные материалы
- утеплитель
- листовые материалы: фанера, OSB, оргалит
- сухие смеси: клей, наливные полы, шпаклевки, штукатурно-клеевые составы
- тротуарные материалы: плитка, брусчатка, бордюры
- инженерка: электрика, вода, канализация
- отделочные материалы
- расходники и мелочёвка
