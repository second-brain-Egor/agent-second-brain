# Опросник 4 — для Telegram-бота (боевые вопросы)

## Когда задавать

После того как опросник 3 пройден. Это второй уровень проверки — более глубокие вопросы про работу системы, твои проекты и память.

## Как использовать

1. Открыть Telegram, найти своего бота.

2. Задавать ему по одному вопросу из списка ниже (просто скопировать текст и отправить).

3. Получать ответ.

4. Скопировать **и вопрос, и ответ бота** в чат с Claude.ai.

5. По оценке Claude.ai — либо «бот работает корректно», либо «вот в этом месте проблема, надо чинить».

Отправлять боту **только текст вопроса**, без префиксов «вопрос 5:» и т.п.

## Вопросы

### Блок А — Понимание истории и контекста

**1.** Сообщение боту:
```
Что мы вчера обсуждали? Дай краткую сводку основных тем.
```

**2.** Сообщение боту:
```
Что я делал на прошлой неделе по проекту бани?
```

**3.** Сообщение боту:
```
Какие задачи у меня сейчас просрочены или близки к дедлайну?
```

**4.** Сообщение боту:
```
Над чем я больше всего работал в апреле?
```

### Блок Б — Связи и поиск по vault

**5.** Сообщение боту:
```

```

**6.** Сообщение боту:
