# Лимиты подписки Claude: где смотреть

## Факт

Из рабочего контура бота (`claude --print`) расход лимитов **не виден**: ответ не содержит
ни процента использования, ни времени сброса окна. Любая цифра, названная в чате «на глаз», —
выдумка.

## Где смотреть по-настоящему

1. Интерактивная сессия Claude Code в терминале — команда `/usage`.
2. Веб-кабинет Anthropic — раздел подписки.

## Правило ответа

На вопрос «как с лимитами / сколько процентов» — короткий честный ответ: изнутри чата не видно,
смотреть через `/usage` в терминале. Не подставлять правдоподобное число.
