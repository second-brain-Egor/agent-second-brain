# Лимиты подписки Claude: как смотреть

## Факт

Расход лимитов подписки Claude виден прямо из бота: команда `claude -p "/usage"`, запущенная через Bash из корня проекта (`/home/egor/agent-second-brain`), отрабатывает сразу, без SSH и интерактивной сессии. Проверено 5 октября 2026 на Claude Code 2.1.289.

Вывод — три строки на английском, в каждой процент использования и время сброса по Москве:

- `Current session` — пятичасовое окно;
- `Current week (all models)` — неделя по всем моделям;
- `Current week (Fable)` — неделя по Fable.

Перед ними бывают служебные предупреждения (например, про правила в `.claude/settings.local.json`) — в ответ не включать.

Прежняя версия этой заметки («из бота расход не виден, смотреть через `/usage` в терминале») была неверной: из-за неё 5 октября 2026 бот ответил Егору «не вижу, запусти по SSH».

## Правило ответа

1. На вопрос о лимитах Claude («сколько процентов», «сколько израсходовано/осталось», «какой лимит») сразу выполнить `claude -p "/usage"` и назвать полученные проценты и время сброса по-русски: пятичасовое окно, неделя по всем моделям, неделя по Fable.
2. Не отправлять Егора в SSH или терминал, не называть цифру по памяти и не выдавать прошлое значение за текущее. Если команда не отработала — назвать ошибку.
3. Это правило только для симки Claude. У Codex проверка другая — `/status` (раздел «Недельный лимит и расход подписки» в `vault/memory/soul.md`).
4. Запускать только по запросу в чате, не по расписанию: cron, таймеры и heartbeat вокруг Claude запрещены (антибан в `CLAUDE.md`).
