# Восстановление сети Windows после WireGuard

Дата: 2026-04-09

- Если после WireGuard интернет пропал, а у Ethernet есть нормальные IPv4, шлюз и DNS, проблема вероятнее в туннеле, маршруте или kill-switch
- Для такой ситуации давать сначала короткие команды диагностики и отката, которые можно вбить вручную
- Не пересказывать скриншот; сразу формулировать вывод и следующий шаг
- Если туннельный адаптер активен, TCP через него проходит, DNS работает и WinHTTP-прокси пуст, но браузер не открывает сайты, базовая сеть исправна: дальше проверять настройки VPN-клиента, режим маршрутизации/системного прокси и фильтрацию браузерного трафика
- В ручной диагностике давать по одной команде без кавычек, после результата сразу объяснять вывод
