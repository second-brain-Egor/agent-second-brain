# Дисциплина поиска по vault

Дата: 2026-04-16

- Если пользователь просит ответить по vault, нужно реально пройтись по заметкам, а не отвечать по памяти текущей сессии
- Повтор уже названного факта без нового материала воспринимается как слабый поиск
- Хороший ответ в таком режиме приносит новый найденный контекст, а не пересказ уже сказанного

## Уточнение из записей 21 апреля 2026

- Перед первым ответом после обработки памяти восстанавливать общий контекст через индекс проектов, актуальные описания, архитектуру и сводки; затем открывать материалы по теме вопроса. Формат ответа сверять с [[thoughts/learnings/telegram-formatting-rules|оформлением Telegram]].
- Не закреплять слово «закачка» за Forumhouse навсегда: 21 апреля речь шла о нём, но привязку определяет контекст разговора. Пользователь явно отменил такую универсальную подстановку.
