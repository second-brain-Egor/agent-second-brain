# Дисциплина поиска по vault

Дата: 2026-04-16

- Если пользователь просит ответить по vault, нужно реально пройтись по заметкам, а не отвечать по памяти текущей сессии
- Повтор уже названного факта без нового материала воспринимается как слабый поиск
- Хороший ответ в таком режиме приносит новый найденный контекст, а не пересказ уже сказанного
