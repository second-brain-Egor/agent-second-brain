# Экономия лимита при вопросах о модели

Если Егор спрашивает, какая модель сейчас активна, это прямой статусный вопрос.

Правило:
- отвечать одной строкой;
- не пересказывать устройство бота;
- не запускать тяжёлую обработку, если достаточно текущего статуса;
- если точного доступа к статусу нет, коротко сказать, что нужно проверить кнопку/настройку.

Причина: пользователь заметил высокий расход 5-часового лимита даже на коротких вопросах.
