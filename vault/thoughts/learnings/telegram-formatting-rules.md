# Правила оформления ответов в Telegram

Дата: 2026-04-13

- Не допускать в тексте сырых HTML-артефактов вроде `br`
- Не использовать сырые Markdown-символы вроде `**`, `##` и кавычки как псевдовыделение
- Не использовать моноширинные кавычки/бэктики вокруг названий папок, файлов и обычных технических слов в пользовательских ответах, если пользователь прямо не просит точное имя как код или команду
- Отвечать по-русски; английские слова, подписи и короткие служебные формулировки переводить на русский, если это не точное имя продукта, команда, путь, API или модель
- Делать короткие абзацы с заметными разрывами между блоками
- Оставлять пустую строку между каждым абзацем
- Не делать лишних пустых строк внутри короткого списка или одного смыслового блока
- Если это отчёт или статусная сводка, оформлять её короткими блоками, а не сплошным текстом
- В отчётах использовать строку-ярлык с двоеточием и ниже короткие пункты по смыслу
- Не использовать `*` для оформления отчётов, если уже зафиксирован предпочтительный чистый вид без звёздочек
- Если используются эмодзи, ставить их в начале абзаца для визуального якоря
- Если ссылки нужны, прятать их в слово или короткое название вместо голого URL
- В карточках товаров и станков ссылка должна быть только в названии модели; отдельную строку с URL не выводить
- Картинки добавлять умеренно, только когда они реально улучшают восприятие
- На короткий прямой вопрос отвечать кратко, без лишнего технического разворота
- Не завершать ответ навязанными предложениями продолжить или что-то ещё сделать
