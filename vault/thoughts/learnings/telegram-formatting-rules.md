# Правила оформления ответов в Telegram

Дата: 2026-04-09

- Не допускать в тексте сырых HTML-артефактов вроде `br`
- Делать короткие абзацы с заметными разрывами между блоками
- Картинки добавлять умеренно, только когда они реально улучшают восприятие
