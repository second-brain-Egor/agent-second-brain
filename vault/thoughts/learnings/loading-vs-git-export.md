# Загрузка без ложного Git-контекста

Если Егор спрашивает «что по загрузке», нельзя отвечать про «выгрузку в Git», пока он сам не назвал Git.

Рабочее правило:
- сначала связать вопрос с реальным текущим процессом: Forumhouse, серверная выгрузка или обработка информации ассистента;
- если контекст неоднозначен, коротко уточнить один раз;
- не вводить новые технические сущности в статус, если их нет в текущем процессе.

Причина: формулировка про Git создаёт ложную картину работ и раздражает пользователя.
