# Единый доступ агентов к Forumhouse

Егор ожидает, что Codex и Claude Code одинаково умеют проверять закачку Forumhouse на Барыге.

Практический смысл:
- не разделять агентов на «может зайти» и «не может зайти», если задача одна и доступ уже отработан;
- переносить рабочий маршрут: SSH-доступ, команды статуса, логи и проверку фактического прогресса;
- если у Claude Code не хватает прав или команд, фиксировать это как настройку контура, а не как пользовательскую проблему.

## Передача инструкции на сервер

По [[daily/2026-04-25|записям 25 апреля]] Егор попросил подготовить конкретную инструкцию для Барыги и положить её на его сервер. При таком поручении результат — размещённый файл с проверенным содержимым; текст в чате не заменяет доставку. Сообщать точное имя файла и подтверждённый результат проверки.

В том обсуждении упоминались верификация и невозможность открыть нужный интерфейс с компьютера. Прохождение верификации, доставка инструкции и восстановление загрузки этим снимком не подтверждены; историческое поручение не считать текущей задачей.
