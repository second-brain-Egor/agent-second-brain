# Forumhouse: авто-реестр выгрузок (с 2026-06-11)

Канон по `ssh barriga` → `/root/forum-harvest`. Полные правила: `/root/forum-harvest/ПРАВИЛА-ВЫГРУЗКИ.md`.

## Суть

- Скрейпер ведёт реестр выгруженных тем: `runtime/exported_threads.json`.
- Фаза `register` в конце каждого цикла `server_sync` автоматически фиксирует все
  complete-темы с диска (заморозка: после выгрузки тема не качается никогда,
  даже при новых постах на форуме).
- Егор просто копирует темы к себе и удаляет с сервера — **ручных отметок нет**.
- Удалённая partial-тема НЕ защищена реестром — перекачается (by design, она недокачана).

## Как проверять «не качает ли по кругу»

1. `runtime/summary.json` → `status_counts`: `exported_pruned` = выгружено и закрыто.
2. Пересечение ID на диске (`data/raw/forumhouse/91/*.json`) с ключами реестра
   должно быть только у тем, которые ещё НЕ удалены пользователем.
3. В `runtime/events.jsonl` фаза `register` должна завершаться `returncode 0`.

## Связанное

- [[loading-vs-git-export]] — различение «загрузка Forumhouse» vs «git push».
- Известная проблема: sync-фаза периодически падает на DDoS-Guard (антибот),
  новые темы качаются только в удачные окна. Это не ошибка реестра.
