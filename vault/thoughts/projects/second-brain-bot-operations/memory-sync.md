# Синхронизация памяти между Telegram и терминалом

Дата: 2026-04-16

- Общая долговременная память у обоих контуров одна: vault, заметки проектов, daily и файлы памяти
- Telegram и терминал могут работать с одной и той же базой знаний, если оба читают и пишут в тот же vault
- Различие остаётся на уровне живой сессии: текущий ход работы, локальные проверки и незаписанные промежуточные мысли не обязаны быть сразу видны в другом контуре
- Для пользователя практический критерий синхронизации простой: если изменение записано в daily, memory или project note, оно должно быть доступно обоим контурам
