# Надёжная остановка торгового бота

## Наблюдение

- После команды остановки бот может продолжать торговать

## Что проверить

- Как именно обрабатывается команда stop
- Есть ли подтверждение остановки и фактическая остановка ордерной логики
- Не остаются ли фоновые процессы или циклы после stop
