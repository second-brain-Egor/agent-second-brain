# АСУЛА: защищённый доступ с планшета

## Требования

- На планшете физически нет GNSS-модуля.
- Интернет даёт отдельный мобильный Wi-Fi-роутер с SIM.
- Локальная модель и рабочие данные остаются на системном блоке.

## Схема

`Планшет → Wi-Fi-роутер с SIM → Tailscale → системный блок → локальная модель`

Tailscale создаёт закрытый зашифрованный канал между разрешёнными устройствами. Сервис модели не публикуется в открытом интернете. Google Диск можно использовать только для контролируемого обмена файлами.

## Проверка моделей Xiaomi

- Xiaomi Pad 7: собственную SIM не поддерживает; в официальной спецификации отдельный GNSS не указан. Подходит только со внешним роутером.
- Xiaomi Pad 5: обычная глобальная версия — Wi-Fi без SIM; спутниковая навигация относилась к отдельной Pad 5 Pro 5G.
