# Скамья под три подушки

Источник: [[daily/2026-09-12]]. Объект размещения не указан; не относить автоматически к даче или Бишайке. Срок изготовления не задан.

## Согласованные ориентиры
- Скамья под три диванные подушки размером примерно по 50 см. Точные размеры подушек не измерены.
- Исходная доска 50×100 мм. Продольный распуск до примерно 25×100 мм рассматривался для отдельных деталей, если получится; для сиденья Егор отдельно потребовал сохранить толщину 50 мм ради жёсткости.
- Высота сиденья в обсуждении — 37 см. Не уточнено, входит ли сюда подушка.
- Ориентир по форме — второй вариант, с более длинным сиденьем; размеры предлагалось восстановить по первому. Присланные ссылки: https://pin.it/6DTDt7yip и https://pin.it/5yLiW7Qw7. При обработке записей чертежи по ним не проверялись.

## Точка остановки
- Обсуждались запилы коротких досок 45° сверху и 40° снизу. Это параметры обсуждения, не проверенный чертёж и не доказанная рекомендация по удобству.
- Последний вопрос: делать короткие элементы из трёх досок либо из двух, разнесённых на 100 мм, с опиранием горизонтальных досок на поперечный брусок.
- Выбор схемы, длины коротких элементов, итоговый раскрой и количество шестиметровых досок не подтверждены. Не считать ранее предложенные шесть досок согласованной закупкой.
