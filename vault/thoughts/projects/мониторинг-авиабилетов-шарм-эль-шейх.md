# Мониторинг авиабилетов в Шарм-эль-Шейх

## Замысел
Егор рассматривает концепцию мониторинга стоимости авиабилетов: скрипт отслеживает цены и при подходящих условиях бронирует билет, оплату Егор выполняет сам. Реализация и запуск пока не согласованы.

## Направление и рамки исследования
Россия → Египет, Шарм-эль-Шейх. Рассматриваются вылеты из Москвы, Санкт-Петербурга, Уфы, Самары и Екатеринбурга. Даты, бюджет и критерии бронирования не заданы.

Сначала нужен список авиакомпаний по каждому городу, затем проверка требований к регистрации, доступа к API и поддержки автоматического бронирования у всех рассматриваемых перевозчиков. Список конкретных билетов на этом этапе не нужен.

В конце интервала Егор сказал «Ну, значит, проверю всех». Это намерение проверить варианты, а не подтверждение завершённой проверки. Результаты исследования и выбранный сервис в переданном интервале отсутствуют; возможности API не подтверждены.

## Состояние
Концепция сохранена. Открытый шаг — проверка перевозчиков и условий автоматического бронирования. Задача в Todoist не создана: проверка существующих задач не выполнена из-за ошибки клиента; при переносе сначала исключить дубли. Срок не задан.
