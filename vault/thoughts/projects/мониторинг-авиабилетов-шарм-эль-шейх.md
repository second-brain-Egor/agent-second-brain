# Мониторинг авиабилетов в Шарм-эль-Шейх

## Замысел
Егор рассматривает концепцию мониторинга стоимости авиабилетов: скрипт отслеживает цены и при подходящих условиях бронирует билет, оплату Егор выполняет сам. 1 октября Егор поручил включить Оренбург, задал окно вылета и режимы бронирования, запросил краткий план. Готовность скрипта и запуск мониторинга не подтверждены.

## Направление и рамки исследования
Россия → Египет, Шарм-эль-Шейх. Рассматриваются вылеты из Москвы, Санкт-Петербурга, Уфы, Самары, Екатеринбурга и Оренбурга. Окно вылета: с 18:00 13 ноября по 14 ноября 2026 включительно. Часовой пояс не уточнён. Бюджет и ценовой порог бронирования не заданы. Для Москвы выбрана автоматическая бронь, для остальных городов — бронь по кнопке; оплату Егор выполняет сам.

Сначала нужен список авиакомпаний по каждому городу, затем проверка требований к регистрации, доступа к API и поддержки автоматического бронирования у всех рассматриваемых перевозчиков. Список конкретных билетов на этом этапе не нужен.

В конце интервала Егор сказал «Ну, значит, проверю всех». Это намерение проверить варианты, а не подтверждение завершённой проверки. Результаты исследования и выбранный сервис в переданном интервале отсутствуют; возможности API не подтверждены.

## Состояние
Концепция сохранена. Открытые шаги — проверить готовность скрипта и подготовить краткий план мониторинга с учётом заданных параметров; проверить перевозчиков и условия автоматического бронирования. Задача в Todoist не создана: проверка существующих задач не выполнена из-за ошибки клиента; при переносе сначала исключить дубли. Срок не задан.
