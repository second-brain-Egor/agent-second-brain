# Летний вариант бани — полубочка из гнутых труб

Временное решение на сезон, пока строится основная [[projects/banny|баня]].

## Конструкция
- 3 дуги, согнутые из 6-метровой квадратной трубы.
- После гибки: высота ≈2 м, радиус ≈2 м.
- Соединить 3 дуги между собой → каркас-ангар в форме полубочки.

## Зонирование
- Парная — утеплённая.
- Остальное — без утепления (летний режим).

## Открытый вопрос — кровля по дугам
Чем накрывать дуги сверху от осадков.

Ранее обсуждалась схема: OSB-3 сплошняком по дугам → подкладочный ковёр → мягкая черепица.

Сомнение Егора: согнётся ли 9-мм OSB-3 по дуге R=2 м. Нужно проверить:
- Минимальный радиус гиба OSB-3 разной толщины (3, 6, 9 мм).
- Где в МО (Вырезанка, Ванциферово) есть OSB-3 в нужной толщине, цена.
- Альтернативы по гнутой кровле: профлист, рулонные мембраны, поликарбонат.

## Что осознанно не делаем
- Не закупаем материал — решение по кровле не принято.
- Не ставим сроков — летний объект, не давит.
