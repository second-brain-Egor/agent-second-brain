Автоматизированная система управления ликвидацией аварии.

## Контекст

Отдельный рабочий проект пользователя внутри общего контура цифрового предприятия.

## Что важно

- держать проект отдельно от личных тем
- связывать с промышленной безопасностью, оперативным управлением и аварийной готовностью
- рабочие материалы и правила группового Telegram-контекста привязывать к этому домену
