# Геометрия скатов: пролёт 6 м

Источник: [[daily/2026-09-09]]. Конкретный строительный объект не назван; расчёт не меняет размеры ранее обсуждавшихся крыш.

Егор сначала назвал угол между стропилами в коньке 56°, затем уточнил уклон ската 8:12 и согласился с углом в коньке около 112,6°. Для продолжения использовать последнюю формулировку.

Проверочный расчёт для симметричной двускатной схемы без свесов:
- Полупролёт 3 м; подъём = 3 × 8 / 12 = 2 м.
- Длина каждой наклонной стороны = √(3² + 2²) = √13 ≈ 3,606 м.
- Угол ската к горизонту = arctan(8/12) ≈ 33,690°; внутренний угол в коньке ≈ 112,620°.
- Исходные 56° между стропилами задавали другую геометрию: сторона = 3 / sin(28°) ≈ 6,390 м. Смешивать этот вариант с уклоном 8:12 нельзя.
