# Постоянно включённый домашний агент

18 апреля Егор рассматривал Raspberry Pi с диском для отдельного агента, работающего через подписку. Цель — держать плату включённой постоянно, без необходимости включать основной компьютер.

Открытые вопросы того обсуждения: выбор платы, питание и энергопотребление, накопитель, совместимость выбранного агента. Покупка или установка не подтверждены; это идея без срока, не активное поручение.

Связано: [[daily/2026-04-18]], [[projects/forumhouse-framehouse-knowledge-base/README|База знаний Forumhouse]].

## Уточнение 20 апреля 2026

Для Claude Code Егор рассматривал Raspberry Pi 5 с накопителем либо маломощный отдельный системник: собственная ОС агента, удалённый доступ к проектам на домашнем ПК и к серверу. Выбор и покупка не подтверждены.

Поводом стало сообщение о блокировке ранее установленного Claude Code. Егор предполагал связь с «засвеченным» оборудованием и просил изучить причины повторных блокировок. Это гипотеза пользователя, а не установленная причина; результатов исследования в исходных записях нет. Исторический запрос не возобновлён.

Отдельную идею небольшой локальной модели вроде Llama под узкую задачу Егор отложил. Позднейшее развитие уже сохранено в [[projects/asula/lora-home-training|проекте дообучения на домашнем ПК]].
