# Прямой веб-контур

Эта директория хранит веб-контур без унаследованных переменных прокси и без
`proxychains`. Прозрачный маршрут сервера через Xray он не меняет: текущий
выход проверяется командой `sudo vpn-guard status`.

- `network.py` очищает proxy-окружение и при необходимости перезапускает Python.
- `browser.py` запускает Chromium с постоянным профилем `browser-profile/` и его
  штатным представлением версии браузера. Статус конечного основного документа
  проверяется после выполнения JavaScript; профиль освобождается и при ошибке.
- `search.py` выполняет веб-поиск через DDGS в прямом окружении.
- `fetch.py` извлекает текст страницы; `responses.py` проверяет HTTP-статус и
  признаки страницы отказа или проверки посетителя.

Чтение по умолчанию сразу идёт через браузер. Простой HTTP-клиент не выполняет
JavaScript, и некоторые сайты отвечают ему проверкой посетителя с кодом 403.
Флаг `--http` выбирает только простой HTTP-запрос, `--browser` оставлен для
совместимости. При отказе загрузчик сообщает причину и не меняет инструмент,
маршрут или учётную запись автоматически. Проверка посетителя не считается
прочитанным материалом, даже если сайт вернул её с HTTP 200.

Публичные команды остаются прежними:

```bash
uv run python scripts/web_search.py "запрос" --max-results 5
uv run python scripts/web_fetch.py "https://example.com"
```

Для явно порученной проверки другого выхода можно передать
`--proxy socks5://127.0.0.1:ПОРТ` (также HTTP/HTTPS). Прокси должен уже работать;
команда не меняет основной Xray или маршруты сервера. Браузер использует
отдельный временный профиль, закрывает его после запроса и не переключается
на другой маршрут при отказе. Адреса прокси с логином и паролем не принимаются.
Название узла в подписке не подтверждает страну его выхода: её проверяют
отдельно через этот же прокси.
