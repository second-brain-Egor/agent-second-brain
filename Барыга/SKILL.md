# Доступ к Барыге

## Когда использовать

Используй этот навык, когда пользователь просит:
- зайти к Барыге
- открыть основной торговый контур Барыги
- проверить что-то в `/root/trading/`
- посмотреть бота, сервисы, логи, баланс или сбор данных в контуре Барыги

## Базовый маршрут входа

Сначала используй текущий проверенный вход:

```bash
ssh barriga
```

Если alias недоступен, используй явный маршрут:

```bash
ssh -i /home/egor/.ssh/id_ed25519 root@185.23.35.88
```

## Рабочий каталог

После входа переходи сюда:

```bash
cd /root/trading
```

## Короткая проверка

Чтобы быстро убедиться, что открыт нужный контур:

```bash
pwd
hostname
```

Ожидаемая рабочая директория:

```text
/root/trading
```

## Правило ответа

Если пользователь спрашивает только, можешь ли зайти, отвечай только фактом входа.

Не расписывай маршрут, ключи, alias и технические детали, если пользователь этого прямо не просил.
