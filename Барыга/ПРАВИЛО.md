# Правило Барыги

Если нужен вход к Барыге, не искать маршрут заново по всей системе.

Сначала использовать текущий проверенный вход:
`ssh barriga`

Если нужен явный вход без alias:
`ssh -i /home/egor/.ssh/id_ed25519 root@185.23.35.88`

Рабочий каталог после входа:
`/root/trading/`
