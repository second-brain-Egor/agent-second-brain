# Правило Барыги

Если нужен вход к Барыге, не искать маршрут заново по всей системе.

Сначала использовать проверенный вход через контур Дельты:
`sudo -u clawd ssh barriga`

Если нужен явный вход без alias:
`sudo -u clawd ssh -i /home/clawd/.ssh/id_ed25519 root@185.23.35.88`

Рабочий каталог после входа:
`/root/trading/`
