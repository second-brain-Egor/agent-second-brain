## Хранение

Бот Ирины работает с `/home/irina/agent-second-brain/vault`.
При загрузке сначала запрашивается выбор пользователя:

- `PDF/` для PDF;
- `Документы/` для остальных форматов;
- `projects/<выбранный проект>/` — прямо в папку проекта.

С 8 октября 2026 у обоих ботов оригинал ложится прямо в выбранную папку, без подпапки
`Документы/` и без отдельной папки на каждый файл. Если там уже лежит такой же файл
(та же контрольная сумма), бот берёт его и копию не создаёт. Другой файл с тем же именем
получает имя `<название> (2).<расширение>`. Служебное лежит в скрытой
`.служебное/<название>/` рядом с оригиналом: `текст.txt`, контрольная сумма текста,
`.document.json`. Готовые материалы прежних автоматических заданий лежат на виду в
`Результаты/<идентификатор задания>/` рядом с оригиналом. Бот Ирины переведён на эту
раскладку вечером 8 октября: её два документа переложены из прежних папок
`<папка>/Документы/<название>-<идентификатор>/`, `Описание.md` убрано в `.служебное/`,
пути в базе обновлены.

С 8 октября 2026 у обоих ботов проект считается корневой папкой: если у проекта есть
подпроекты или проект новый, бот после его названия спрашивает подпроект. Кнопки — подпапки проекта (кроме скрытых), «В корень
«<проект>»» и «➕ Новый подпроект». Отвечать можно и текстом или голосом: название
подпроекта (регистр, «ё» и точка в конце не важны), «в корень», «новый подпроект <название>».
Незнакомое название без слова «новый» папку не создаёт — бот переспрашивает. Название
проекта тоже сверяется с существующими папками без учёта регистра; для несуществующего
проекта бот предупреждает, что заведёт новую папку. Выбранный проект и показанный список
подпроектов хранятся в таблице `subproject_choice` (состояния документа `subproject` и
`subproject_new`). После сохранения бот пишет, куда положил файл (проект, подпроект,
путь), и, если в корне проекта есть `Журнал документов.md`, добавляет строку в его раздел
«Записи».

### Текущий проект (оба бота, с 8 октября 2026)

Бот помнит проект беседы (таблица `active_project`) и кладёт туда новые документы и фото
без вопросов: в выбранный подпроект или в корень проекта. Фото называются
`фото ГГГГ-ММ-ДД ЧЧ-ММ-СС.jpg`; без текущего проекта они ждут во входящих, как документы
(раздел ниже). Текущим проект становится, когда пользователь выбирает его для файла,
или когда помощник переключает его по ходу разговора:
`uv run python scripts/project_context.py --scope <id> set|show|clear|list|move`.
Если проект не трогали `ACTIVE_HOURS` (12 часов), бот снова спрашивает папку.

Каждый файл, положенный ботом сам, записывается в таблицу `placements` как непроверенный.
Помощник видит их в блоке «НОВЫЕ ФАЙЛЫ: ПРОВЕРЬ МЕСТО» своего промпта. Он сверяет место
и при сомнении спрашивает; переносит только после ответа. Отметка «проверено» ставится
после успешного ответа в чате. Отдельного таймера нет: проверка идёт при следующем сообщении.

Без текущего проекта вопрос о папке показывает кнопками пять последних проектов (последний
текущий — первым), «📋 Все проекты» и общую папку PDF/Документы. Можно ответить названием
проекта текстом или голосом. Проект без подпроектов принимает файл сразу в корень, второго
вопроса нет.

До выбора папки новая загрузка находится в `.documents/incoming/`.
Повторные загрузки с одинаковой контрольной суммой в одном чате используют
зарегистрированный оригинал. Старый файл из `attachments/` остаётся на месте
до выбора папки, затем переносится. Повторно загружать его не нужно.

Состояние выбора, привязка сообщений и очередь находятся в
`.documents/state.sqlite3`. Общая память содержит только название и путь;
папки документов исключены из индекса Markdown. Полный текст не добавляется
в сессию и ежедневные записи. Временные изображения OCR удаляются автоматически.
Не выбранные пользователем документы автоматически не удаляются.

## Обработка и восстановление

Подпись к файлу, отдельный текст и расшифрованное голосовое сообщение направляются
в одну очередь. До выбора папки обработка не начинается. Модель получает
извлечённый текст и возвращает структуру результата; файл создаётся и проверяется
программно. Большой текст передаётся через локальный файл без молчаливого обрезания.

Для презентаций без указанного формата бот спрашивает: «В каком формате
подготовить презентацию — PowerPoint (.pptx) или PDF?» Ответ принимается кнопкой,
текстом или расшифрованным голосом. Если формат уже указан, вопрос пропускается.
Исходное задание и ожидаемый выбор сохраняются в таблице `presentation_choices`
той же базы `.documents/state.sqlite3`. До выбора генерация не запускается.
Выбор и постановка задания по документу в очередь записываются одной транзакцией;
повторное нажатие не создаёт повторное задание. Название PDF-источника само по себе
не задаёт формат презентации. Вопрос о папке сохраняется отдельно и задаётся первым.
Для презентаций без загруженного источника после выбора продолжается обычный диалог
с исходным заданием и явно указанным форматом результата.

Чтение документа, распознавание страниц и генерация не ограничены по времени. При временной ошибке
или некорректном результате модели разрешена одна повторная попытка.
После перезапуска незавершённая обработка восстанавливается в пределах двух попыток.

У Telegram нет ключа идемпотентности для отправки файла. Если отправка прервалась
и подтверждение не получено, автоматической пересылки нет: пользователю доступна
кнопка повторной отправки. Это предотвращает автоматические дубликаты, но не
означает гарантированную доставку при обрыве связи. Подтверждённая отправка
сохраняет номер сообщения в базе и повторно не выполняется.
